# 🎵 音乐文件

## 快速下载（点击链接在浏览器中打开）

| 文件名 | 推荐下载链接 | 用途 |
|--------|-------------|------|
| `bgm-happy.mp3` | https://pixabay.com/music/search/children%20happy/ | 主页音乐 |
| `bgm-lesson.mp3` | https://pixabay.com/music/search/kids%20background/ | 课程页音乐 |

## 下载步骤
1. 打开上面的 Pixabay 链接
2. 选一首喜欢的音乐
3. 点击"Download"按钮
4. 将下载的文件重命名为 `bgm-lesson.mp3`，放入当前文件夹

## 没有 MP3 也能用！
每节课都内置了 Web Audio API 合成音乐引擎，没有 MP3 文件时自动播放合成背景音乐。
点击页面右上角 🎵 按钮即可开关。
