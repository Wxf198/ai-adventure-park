📖 Knowledge

1. Learning Like Memorizing Vocabulary — Supervised Learning

📝 What Is Supervised Learning?

Imagine you have a stack of cards, each with a label on it:

🐱
Label: Cat
Features: Pointy ears, whiskers, small body
🐕
Label: Dog
Features: Floppy ears, long snout, larger body

AI looks at these labeled cards → finds patterns → classifies new images. Just like doing a workbook where you can check against the answer key!

💡 Key terms: Labeled data = training data; The patterns found = model; Using the model on new data = prediction

📖 Knowledge

3. Learning Like Scoring in a Game — Reinforcement Learning

🎮 What Is Reinforcement Learning?

There is no answer key! AI can only try things out and receive rewards or penalties:

  • ✅ Right action → +10 points
  • ❌ Wrong action → -5 points

The AI's goal is simple: Maximize the total score!

🏓 Interactive Demo: Teach AI to Catch the Ball

A ball falls — drag the paddle to catch it. Each catch = AI learns a good strategy. Each miss = needs improvement.

💡 This is reinforcement learning! Each catch = positive reward, each miss = negative feedback. After thousands of attempts, AI learns the best strategy.
In reality, AlphaGo works the same way — it played millions of games against itself to learn!
